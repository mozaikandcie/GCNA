# GCNA
One Page du grand chanté nwèl de l'association Ambyans twopikal

## Site

Site statique (HTML / CSS / JS vanilla), sans build. Déployé sur Vercel depuis `main`.

- `index.html` — page principale · `css/` · `js/` · `assets/`
- `js/config.js` — dates, endpoint du rappel e-mail, URL de partage
- `reglement.html`, `mentions-legales.html`, `confidentialite.html` — squelettes à compléter
- Les points ouverts sont marqués `TODO` dans `index.html` (`grep -n TODO index.html`)

En local : `python3 -m http.server 8000`, puis http://localhost:8000
